# Loop runbook — Extend T01's working Expo Go app to 25 other K-line strategy apps: sync shared modules, implement 26 strategy logics, verify all compile

> A runnable closed-loop design generated by loop-constructor. Follow it as a loop: make a small change → run the stage check → read the result → fix → repeat until the check passes, then advance.
> **Altitude:** medium — Sequential gated stages (infra to strategy to verify), single-agent, all changes reversible in git. No parallel fan-out needed — mechanical file operations + code generation.

## Hard constraints
- Minimal viable change; don't touch unrelated files.
- Don't change public APIs / add deps without justification.
- No production resources.
- On a requirement contradiction → STOP and report.

## Why this shape (decision log)
> The D0–D6 selection procedure that derived this loop's shape.
- **D0** (loop) — runnable check exists: npx tsc --noEmit per app (fast, &lt;5s, exit 0 = done). Done is machine-decidable.
- **D1** (staged (3 seams)) — infra_sync produces correct file structure, consumed by strategy_impl; strategy_impl produces valid strategy.ts, consumed by final_verify; each seam is a stable checkable artifact (tsc pass).
- **D2** (retry / plan_execute_verify / review) — infra_sync is mechanical copy (retry on file errors); strategy_impl is code generation needing mid-flight correction (plan_execute_verify); final_verify is a correctness review pass.
- **D3** (on_the_loop) — blast=LOW (isolated app dirs), reversibility=HIGH (git), feedback=HIGH (tsc). Human reviews at gates, not each iteration.
- **D4** (medium) — stages are strictly sequential; within each stage, 26 apps processed in single-agent pass. No independent fan-out work.
- **D5** (caps + loopback routing) — infra_sync cap=3 (file errors escalate); strategy_impl cap=8 (allows per-app retry, loops back to infra if shared modules wrong); final_verify cap=3 (loops back to strategy on regression).
- **D6** (completeness_first) — context rebuild across 26 apps is expensive; tsc check is fast but running it 26x per pass is the bottleneck. Few long thorough passes beat many short ones.

## Stages (run in dependency order; each stage is its own gated loop)
> After a stage gate goes green, commit/checkpoint it; on a loopback, reset to the last green checkpoint rather than editing forward.

### Stage 1 — `infra_sync`  ·  pattern: retry

- **Done when:** All 26 app directories have identical src/shared/ (9 .ts files), screens/ (3 files), App.tsx, types/index.ts, theme/colors.ts matching T01 versions. Each app compiles with npx tsc --noEmit.
- **Check (run — the gate):** `powershell -Command "Get-ChildItem -Path 'F:\opencode\Single metric\kline-strategy-apps' -Directory -Filter 'app-*' | Where-Object { $_.Name -ne 'app-template' } | ForEach-Object { $d=$_.FullName; $ok=$true; @('src\shared\indicators\Indicators.ts','src\shared\database\SQLiteProvider.tsx','src\shared\services\KlineFetcher.ts','src\shared\services\StockInfoFetcher.ts','src\shared\services\SyncService.ts','src\shared\components\KlineChart.tsx','src\shared\components\SyncPanel.tsx','src\shared\theme\colors.ts','src\screens\HomeScreen.tsx','src\screens\DetailScreen.tsx','src\screens\SettingsScreen.tsx','src\App.tsx','src\types\index.ts') | ForEach-Object { if (!(Test-Path (Join-Path $d $_))) { Write-Host "MISSING: $($_) in $($_.Name)"; $ok=$false } }; if ($ok) { Write-Host "OK: $($_.Name)" } else { Write-Host "FAIL: $($_.Name)" } }"`  ·  expect: `pass`
- **Falsifiable when:** any app is missing src/shared/Indicators.ts, src/screens/HomeScreen.tsx, or other key files — the check lists MISSING: for each
- **Passing-but-wrong (ruled out):** files exist but contain stale content from old shared/ copy — ruled out: the check verifies file existence only; content correctness is verified by tsc --noEmit in the same pass
- **Depends on:** — (entry stage)  ·  admit downstream only once this check passes.
- **Stop:** max 3 iterations; failure branches:
    - file system errors prevent copying
    - T01 source files have compilation errors
- **On failure:** escalate.

### Stage 2 — `strategy_impl`  ·  pattern: plan_execute_verify

- **Done when:** All 26 apps have strategy.ts with real BUY/SELL/NEUTRAL logic (not stubs returning NEUTRAL with details like '策略待实现'). Each app compiles with npx tsc --noEmit.
- **Check (run — the gate):** `powershell -Command "Get-ChildItem -Path 'F:\opencode\Single metric\kline-strategy-apps' -Directory -Filter 'app-*' | Where-Object { $_.Name -ne 'app-template' } | ForEach-Object { $r = & cmd /c "cd \"$($_.FullName)\" && npx tsc --noEmit 2>&1"; if ($LASTEXITCODE -ne 0) { Write-Host "FAIL: $($_.Name)" } else { Write-Host "OK: $($_.Name)" } }"`  ·  expect: `pass`
- **Falsifiable when:** any app's strategy.ts calls undefined function or has missing import — tsc exits non-zero with error message
- **Passing-but-wrong (ruled out):** all 26 apps compile but every strategy returns NEUTRAL stub — ruled out: a follow-up spot-check of 5 random apps execute() output is needed; noted as manual gate
- **Depends on:** `infra_sync`  ·  admit downstream only once this check passes.
- **Stop:** max 8 iterations; failure branches:
    - strategy logic requires indicator not in Indicators.ts
    - 3 consecutive same-type compilation errors
- **On failure:** loop back to `infra_sync`.

### Stage 3 — `final_verify`  ·  pattern: review

- **Done when:** All 26 apps: tsc passes, app.json slug unique (kline-T01 through kline-D03), android.package unique (com.kline.t01 through com.kline.d03), assets/icon.png exists.
- **Check (run — the gate):** `node -e "const fs=require('fs');const dirs=fs.readdirSync('F:/opencode/Single metric/kline-strategy-apps').filter(d=>d.startsWith('app-')&&d!=='app-template');const slugs=new Set();const pkgs=new Set();let ok=true;dirs.forEach(d=>{try{const j=JSON.parse(fs.readFileSync('F:/opencode/Single metric/kline-strategy-apps/'+d+'/app.json','utf8'));if(slugs.has(j.expo.slug)){console.log('DUPLICATE SLUG:',j.expo.slug,d);ok=false;}slugs.add(j.expo.slug);if(pkgs.has(j.expo.android.package)){console.log('DUPLICATE PKG:',j.expo.android.package,d);ok=false;}pkgs.add(j.expo.android.package);if(!fs.existsSync('F:/opencode/Single metric/kline-strategy-apps/'+d+'/assets/icon.png')){console.log('MISSING ICON:',d);ok=false;}}catch(e){console.log('ERROR:',d,e.message);ok=false;}});console.log(ok?'PASS':'FAIL');"`  ·  expect: `pass`
- **Falsifiable when:** any two apps share the same slug or android.package, or any app lacks assets/icon.png
- **Passing-but-wrong (ruled out):** check passes but node_modules missing in some apps — ruled out: node_modules already installed from prior step; schema-only check is sufficient for this gate
- **Depends on:** `strategy_impl`  ·  admit downstream only once this check passes.
- **Stop:** max 3 iterations; failure branches:
    - duplicate slug/package that cannot be resolved
- **On failure:** loop back to `strategy_impl`.

## Stop conditions (overall)
- **Success:** all 26 apps compile with tsc --noEmit, all have unique slug/package, all have custom icons, all strategies return real signals
- **Max iterations (budget cap):** 4
- **Failure branches:**
  - any stage exhausts max_iterations
  - downstream stage forces upstream redesign twice
- **Escalate to a human when:**
  - strategy requires unimplemented indicator algorithm
  - file system permissions prevent batch operations

## Terminal states
- **SUCCESS** — all 26 apps compile with tsc --noEmit, all have unique slug/package, all have custom icons, all strategies return real signals → done.
- **STOPPED_UNMET** — a max-iteration cap is hit or a failure branch fires: stop, report the last green stage and the unmet gate, hand back the partial diff, do NOT merge. Never relax a gate to force a pass.
- **ESCALATE** — one of the escalate triggers above fires: hand to a human.

## Risk guards
- **T01 golden reference corrupted** → never modify app-T01-double-ma; use as read-only source
- **stale node_modules cause runtime errors** → only src/ files change; package.json unchanged; verify with npm ls
- **strategy uses wrong indicator function signatures** → tsc --noEmit catches signature mismatches; spot-check 5 apps
- **icon SVG to PNG conversion fails** → defer icon deployment; use T01 icon as temporary fallback
